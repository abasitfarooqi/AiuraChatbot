Unified Configuration

This is the central configuration file for your chatbot. All settings including business info, company details, prompts, chatbot service settings, and application config are managed here. Perfect for multi-vendor and multi-business use!

Switch between versions or create new ones. "Current" is the active version in use.
Key Sections:
• business - Company name, services, branches
• contact - Phone, email, contact format
• prompts - System prompts (use variables like {company_name}, {contact_email})
• chatbot_service - Greetings, suggestions, topic detection, response formatting
• application - API settings, database, embedding, LLM config

Variables available: {company_name}, {company_name_lower}, {contact_phone}, {contact_email}, {services_list}, {primary_service}, {contact_format}
